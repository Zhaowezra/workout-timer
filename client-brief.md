# Description of the Workout Timer app


Create a simple frontend only workout timer PWA

It should allow you to define the number of rounds, the amount of 'work' in that round and the amount of 'rest' in that round

Ideally it would run while the screen is off

The ui should be simple and minimal

It should beep a 3 second countdown between work and rest and rounds but a gentle one, with the loudest one at the end
